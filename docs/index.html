Buckingham Π, made practical

Enter physical variables and their units, then find independent dimensionless groups using exact rational linear algebra. Choose preferred repeating variables when you want a particular form.

The same calculation engine is available as a small Python package. The webpage runs entirely on your device through Pyodide; no server and no upload are required.
